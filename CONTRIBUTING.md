# Contributing

Thanks for considering a contribution.

## Local Setup

```powershell
python -m pip install -e ".[dev]"
python -m pytest -v
```

## Pull Requests

- Keep changes focused.
- Add or update tests for behavior changes.
- Run `python -m pytest -v` before opening a pull request.
- Keep application guidance truthful and evidence-based.
- Do not add automation that submits forms.
- Do not fabricate project metrics, adoption claims, maintainer status, or ecosystem importance.

## Truthfulness Requirement

This project exists to help maintainers prepare honest application drafts. Contributions must preserve that purpose. When a field is unknown, the tool and docs should make that uncertainty visible instead of filling it with unsupported claims.
